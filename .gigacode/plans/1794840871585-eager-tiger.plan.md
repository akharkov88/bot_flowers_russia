# Plan: Navigation Stack for Back Button

## Summary
Replace fragile FSM-based back navigation with a **navigation stack** stored in FSM state. Each forward navigation pushes current screen onto the stack; each back press pops the stack and restores the previous screen.

## Navigation Hierarchy
```
Главное меню → 🌸 Каталог → 📂 Категории → 🌹 Продукты → 🔍 Детали товара → 🛒 Корзина
```

## Files to Modify

### 1. NEW: `/bot/handlers/navigation.py` — Navigation helpers
- `push_navigation(state, screen, **kwargs)` — push new screen, save current context
- `pop_navigation(state)` — pop stack, return previous context
- `clear_navigation(state)` — clear stack
- `save_cart_back_context(state)` / `get_cart_back_context(state)` — cart-specific context
- Constants: `SCREEN_MAIN_MENU`, `SCREEN_CATEGORIES`, `SCREEN_PRODUCTS`, `SCREEN_PRODUCT`

## How It Works

### Forward Navigation (push)
```
Main Menu → Каталог
  stack: [] → [{"screen": "categories", "cat_id": 0}]

Categories → Products
  stack: [{"screen":"categories"}] → [{"screen":"categories"}, {"screen":"products","cat_id":123}]

Products → Product Detail
  stack: [..., {"screen":"products"}] → [..., {"screen":"product","cat_id":123,"product_id":456}]
```

### Back Navigation (pop)
```
Product Detail → Back
  pop → restore {"screen":"products","cat_id":123} → show products list

Products → Back
  pop → restore {"screen":"categories","cat_id":0} → show categories

Categories → Back
  stack empty → show main menu
```

### Cart Back
```
Cart → Back → if saved cat_id > 0 → restore category products
                        → else → main menu
```
