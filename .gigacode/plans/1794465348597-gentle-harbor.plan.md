# План редизайна админ-панели в русском народном стиле

## Цель
Переоформить админ-панель (`admin_web/`) в стилистике изображений: традиционный русский орнамент, красно-чёрно-белая палитра, декоративные рамки, цветочные мотивы, тёмный фон.

## Файлы для изменения

### 1. `admin_web/static/css/style.css` — полный редизайн
- **Палитра**: `--bg: #1A1A1A` (тёмный фон), `--primary: #C41E3A` (красный), `--accent: #D4AF37` (золото), `--text: #F5E6D3` (кремовый), `--white: #1E1E1E` (карточки), `--border: #3D2B2B` (бордер)
- **Шрифт**: подключить Google Fonts — `Ruslan Display` (заголовки, русский стиль) + `Cormorant Garamond` (текст)
- **Navbar**: тёмный фон с красным орнаментальным бордюром (CSS repeating-linear-gradient или SVG pattern), шрифт Ruslan Display для brand
- **Орнаментальные бордюры**: CSS-паттерны через `repeating-linear-gradient` или inline SVG для имитации народного орнамента (хохлома/гжель)
- **Cards**: тёмные карточки с красной декоративной рамкой, тень с красным свечением, уголки-орнамент через pseudo-elements
- **Tables**: тёмный фон, заголовки таблицы с красным градиентом и орнаментом, чередующиеся строки с лёгким красным оттенком
- **Stat cards**: крупные значения с золотым акцентом, декоративная рамка
- **Buttons**: красные с золотым бордером, hover с орнаментальным эффектом
- **Forms**: тёмные поля с красным фокусом, декоративные label
- **Login page**: тёмный фон с красным орнаментальным паттерном, декоративная рамка формы
- **Decorative elements**: CSS-классы для орнаментальных разделителей (`ornament-divider`), цветочных мотивов через pseudo-elements

### 2. `admin_web/templates/base.html` — обновление
- Подключить Google Fonts в `<head>`
- Добавить декоративный орнаментальный бордюр сверху navbar (через pseudo-element или отдельный div)
- Добавить SVG-орнамент в конец body для декоративного нижнего бордюра

### 3. `admin_web/templates/dashboard.html` — декоративные улучшения
- Добавить орнаментальный разделитель после заголовка
- Декоративные уголки на stat-card (через CSS)

### 4. `admin_web/templates/login.html` — декоративные улучшения
- Добавить орнаментальную рамку вокруг login-box
- Декоративный разделитель

### 5. Остальные шаблоны — минимальные изменения
- `categories.html`, `products.html`, `customers.html`, `orders.html` и др. — CSS-классы уже определены в style.css, визуальные изменения произойдут автоматически

## Технические детали

### CSS орнаментальные паттерны
```css
/* Орнаментальный бордюр через градиент */
.ornament-border {
    border-image: repeating-linear-gradient(
        45deg,
        var(--primary),
        var(--primary) 5px,
        transparent 5px,
        transparent 10px,
        var(--accent) 10px,
        var(--accent) 15px
    ) 10;
}
```

### SVG орнамент (inline в base.html)
Простой паттерн с цветочными мотивами и геометрическим орнаментом в стиле хохломы.

### Google Fonts
```html
<link href="https://fonts.googleapis.com/css2?family=Ruslan+Display&family=Cormorant+Garamond:wght@400;500;600;700&display=swap" rel="stylesheet">
```

### Декоративные уголки для карточек
Через `::before` и `::after` с border-элементами в красном цвете.

## Порядок выполнения
1. Редизайн `style.css` — основной файл стилей
2. Обновление `base.html` — шрифты и декоративные элементы
3. Обновление `dashboard.html` — орнаментальные разделители
4. Обновление `login.html` — декоративная рамка
5. Проверка всех страниц

## Верификация
- Открыть каждую страницу админ-панели: Dashboard, Orders, Products, Categories, Customers, Login, Stats
- Проверить: тёмный фон, красные акценты, орнаментальные элементы, читаемость текста, адаптивность на мобильных
- Проверить: шрифты Ruslan Display (заголовки) и Cormorant Garamond (текст) загружаются корректно
