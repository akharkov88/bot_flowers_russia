# План: Отслеживание брошенных корзин + чат с клиентами

## Контекст
Сейчас корзина хранится только в FSM-памяти бота и теряется при перезапуске. Нет отслеживания пользователей, которые начали заказ, но не завершили.

## Требования
1. Персистентное хранение корзины (в БД)
2. Отслеживание брошенных корзин (корзина есть, заказа нет)
3. Отображение таких пользователей в админке
4. Возможность написать пользователю от имени бота
5. Поддержка диалога с клиентом (админ продолжает переписку)

---

## Шаг 1. Модель `Cart` в БД

**Файл:** `bot/models.py`

```python
class Cart(Base):
    __tablename__ = "carts"
    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(Integer, ForeignKey("users.id"), nullable=False)
    telegram_id = Column(Integer, nullable=False)  # для быстрого доступа
    data = Column(Text, nullable=False)  # JSON: {"product_id": quantity, ...}
    total_price = Column(Float, default=0.0)
    status = Column(String(20), default="active")  # active | completed | abandoned
    created_at = Column(DateTime, default=lambda: datetime.now(timezone.utc))
    updated_at = Column(DateTime, default=lambda: datetime.now(timezone.utc), onupdate=lambda: datetime.now(timezone.utc))
    abandoned_at = Column(DateTime, nullable=True)
```

**Поля:**
- `data` — JSON-строка `{"1": 2, "3": 1}` (product_id → quantity)
- `status` — отслеживание статуса корзины
- `abandoned_at` — когда корзина помечена как брошенная

## Шаг 3. Обновление логики корзины (`cart.py`)

**Файл:** `bot/handlers/cart.py`

### Изменения:
1. При добавлении товара в корзину — сохранять в БД
2. При изменении количества — обновлять запись в БД
3. При очистке корзины — помечать как `completed` или `deleted`
4. При создании заказа — переносить корзину в заказ и удалять запись
5. Рассчитывать `total_price` из данных корзины

### Ключевые изменения:
```python
# При добавлении товара
```

## Шаг 4. Отслеживание брошенных корзин

**Файл:** `bot/handlers/order.py` + `bot/main.py`

### Логика:
1. При отмене заказа (`отмена` в любом шаге) — помечать корзину как `abandoned` с `abandoned_at = now()`
2. При успешном заказе — помечать корзину как `completed`
3. Фоновая задача (каждые 30 мин) — помечать корзины старше 24 часов как `abandoned`

## Шаг 7. Реалтайм-чат: пересылка сообщений

### 7.1. Админ отправляет сообщение

1. Админ вводит текст в форму чата
2. Создаётся запись `Message(direction='outgoing')` в БД
3. Создаётся `Notification(telegram_id=user.telegram_id)` для отправки ботом
4. Бот отправляет сообщение пользователю
5. В админке сообщение появляется в истории

### 7.2. Обработка ответов от пользователя

**Файл:** `bot/handlers/admin.py`

## Проверка
1. Пользователь добавляет товары в корзину → корзина сохраняется в БД
2. Пользователь отменяет заказ → корзина помечается abandoned
3. В админке → "Брошенные корзины" → видны пользователи с товарами
4. Админ нажимает "Написать" → сообщение приходит пользователю
5. Пользователь отвечает → админ видит ответ в чате
