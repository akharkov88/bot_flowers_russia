# План: Учёт количества товаров в наличии

## Цель
Добавить поле «количество единиц» (quantity) для товаров, чтобы:
- Администратор мог указывать количество единиц на складе
- При заказе нельзя было заказать больше, чем есть в наличии
- Покупатели видели доступное количество в каталоге

## Изменяемые файлы

| Файл | Изменение |
|------|-----------|
| `bot/models.py` | Добавить поле `quantity` в Product |
| `migrations/versions/` | Новая миграция Alembic |
| `admin_web/routes.py` | Принимать `quantity` в add/edit |
| `admin_web/templates/product_form.html` | Поле ввода количества |
| `admin_web/templates/products.html` | Отображение количества в таблице |

| `bot/handlers/order.py` | Проверка остатка при оформлении заказа |
| `bot/handlers/catalog.py` | Показывать количество в карточке товара |

## Шаг 7: Бот — корзина (`bot/handlers/cart.py`)

### `action == "add"` — проверка при добавлении:
```python
# После получения product:
if product.quantity <= 0:
    await callback.answer("❌ Товар закончился!")
    return
# Проверяем, чтобы не превысить доступное количество
current_qty = cart.get(str(prod_id), 0)
if current_qty + 1 > product.quantity:
    await callback.answer(f"❌ В наличии только {product.quantity} шт.!")
    return
```

### `action == "plus"` — проверка при увеличении:
```python
# Перед инкрементом:
if cart.get(prod_id, 0) + 1 > product.quantity:
    # Запросить product из БД
    result = await db_session.execute(select(Product).where(Product.id == int(prod_id)))
    p = result.scalar_one_or_none()
    if p:
        await callback.answer(f"❌ В наличии только {p.quantity} шт.!")
    else:
        await callback.answer()
    return
```

## Шаг 8: Бот — оформление заказа (`bot/handlers/order.py`)

### `process_comment` — проверка перед созданием заказа:
```python
# Перед созданием Order:
for prod_id_str, qty in cart.items():
    prod_id = int(prod_id_str)
    result = await db_session.execute(select(Product).where(Product.id == prod_id))
    product = result.scalar_one_or_none()
    if not product:
        continue
    if qty > product.quantity:
        await message.answer(
            f"❌ Товар «{product.name}» — в наличии только {product.quantity} шт. "
            f"Вы заказали {qty} шт.\n\n"
            f"Откорректируйте корзину или уменьшите количество."
        )
        return
```

1. **Админка**: открыть `/products/add` — поле «Количество единиц» присутствует
2. **Админка**: открыть `/products` — колонка «Кол-во» отображается

7. **Миграция**: `alembic upgrade head` проходит без ошибок
