# План: Изменение порядка категорий (drag-and-drop)

## Цель
Добавить возможность менять порядок отображения категорий в Telegram-боте через админ-панель с помощью drag-and-drop.

## Изменяемые файлы

| Файл | Действие |
|------|----------|
| `bot/models.py` | Добавить поле `sort_order` в модель `Category` |
| `bot/handlers/catalog.py` | Обновить запрос — сортировка по `sort_order` вместо `id` |
| `admin_web/routes.py` | Обновить запрос категорий — сортировка по `sort_order`; добавить API endpoint для перестановки |
| `admin_web/templates/categories.html` | Добавить drag-and-drop UI для перетаскивания строк категорий |
| `migrations/versions/XXXX_add_sort_order_to_categories.py` | Новая миграция Alembic |
| `seed_data.py` | Установить начальные `sort_order` для существующих категорий |

---

## Шаг 1: Модель — добавить `sort_order`

**Файл:** `bot/models.py`

В модель `Category` добавить поле:

```python
sort_order = Column(Integer, default=0, nullable=False)
```

- `default=0` — для существующих записей (будет переопределено миграцией)
- `nullable=False` — обязательное поле

---

## Шаг 2: Миграция Alembic

Создать новую миграцию:

```bash
alembic revision -m "add_sort_order_to_categories"
```

Содержимое миграции (`migrations/versions/XXXX_add_sort_order_to_categories.py`):

```python
def upgrade():
    op.add_column('categories', sa.Column('sort_order', sa.Integer(), nullable=False, server_default='0'))

def downgrade():
    op.drop_column('categories', 'sort_order')
```

---

## Шаг 3: Обновить запросы в боте

**Файл:** `bot/handlers/catalog.py` (строка ~30)

Заменить:
```python
.select(Category).where(Category.is_active == True, subquery)
.order_by(Category.id)
```

На:
```python
.select(Category).where(Category.is_active == True, subquery)
.order_by(Category.sort_order, Category.id)
```

---

## Шаг 4: Обновить запросы в админке

**Файл:** `admin_web/routes.py`

Во всех запросах категорий заменить `.order_by(Category.id)` на:
```python
.order_by(Category.sort_order, Category.id)
```

Это затрагивает:
- `@router.get("/categories")` — список категорий
- `@router.get("/categories/{id}/edit")` — страница редактирования (загрузка списка для выбора категории при создании продукта)

## Шаг 5: API endpoint для перестановки

**Файл:** `admin_web/routes.py` (или `admin_web/api.py`)

Добавить POST endpoint:

```python
@router.post("/categories/reorder")
async def categories_reorder(request: Request):
    data = await request.form()
    category_ids = data.get("ids", "")  # строка вида "3,1,4,2,5"
    ids = [int(x) for x in category_ids.split(",") if x.strip()]
    
    async with async_session() as session:
        for index, cat_id in enumerate(ids):
            cat = await session.get(Category, cat_id)
            if cat:
                cat.sort_order = index
        await session.commit()
    
    return redirect(url_for("categories_page"))
```

## Шаг 6: Drag-and-drop UI в админке

**Файл:** `admin_web/templates/categories.html`

### HTML-изменения:
- Добавить `draggable="true"` атрибут на каждую строку таблицы (`<tr>`)
- Добавить `id="category-row-{id}"` для идентификации строк
- Добавить скрытую форму с полем `ids` для отправки нового порядка
- Добавить кнопку "Сохранить порядок"

### JavaScript:
- Реализовать drag-and-drop через HTML5 Drag & Drop API:
  - `dragstart` — сохранять индекс перетаскиваемой строки
  - `dragover` — разрешать drop (e.preventDefault())
  - `drop` — менять местами строки в DOM
  - `dragend` — активировать кнопку "Сохранить порядок"
- При клике на "Сохранить порядок":
  - Собрать текущий порядок ID из строк таблицы
  - Отправить POST на `/categories/reorder`
  - Обновить страницу

Примерная структура JavaScript:

```javascript
let draggedRow = null;

document.querySelectorAll('.category-row').forEach(row => {
    row.addEventListener('dragstart', e => {
        draggedRow = row;
        e.dataTransfer.effectAllowed = 'move';
    });
    row.addEventListener('dragover', e => {
        e.preventDefault();
        e.dataTransfer.dropEffect = 'move';
    });
    row.addEventListener('drop', e => {
        e.preventDefault();
        if (draggedRow !== row) {
            const rows = [...document.querySelectorAll('.category-row')];
            const draggedIdx = rows.indexOf(draggedRow);
            const droppedIdx = rows.indexOf(row);
            if (draggedIdx < droppedIdx) {
                row.after(draggedRow);
            } else {
                row.before(draggedRow);
            }
            document.getElementById('save-order-btn').disabled = false;
        }
    });
});

document.getElementById('save-order-btn').addEventListener('click', async () => {
    const ids = [...document.querySelectorAll('.category-row')]
        .map(row => row.dataset.categoryId);
    const form = document.createElement('form');
    form.method = 'POST';
    form.action = '/categories/reorder';
    const input = document.createElement('input');
    input.type = 'hidden';
    input.name = 'ids';
    input.value = ids.join(',');
    form.appendChild(input);
    document.body.appendChild(form);
    form.submit();
});
```
