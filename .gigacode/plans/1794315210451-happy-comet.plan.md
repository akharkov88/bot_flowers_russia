# План: Множественные фотографии товаров

## Контекст
- Текущая реализация: одно поле `image_url` в модели `Product`
- Нужно: несколько фотографий на товар с возможностью добавления/удаления
- Отображение всех фото в Telegram при просмотре товара

## Требования
1. Создать таблицу `product_images` для хранения фотографий
2. Связь Product 1:N с ProductImage
3. Веб-панель: загрузка нескольких фото, превью, удаление
4. Telegram: отображение всех фото товара

## Шаг 1: Модель данных

### Файл: `bot/models.py`
- Добавить модель `ProductImage`:
  - `id` (Integer, PK)
  - `product_id` (Integer, FK → products.id)
  - `image_url` (String)
  - `order` (Integer) — порядок отображения
  - `created_at` (DateTime)
  - relationship с Product

### Файл: `bot/models.py`
- Обновить `Product`:
  - Добавить `images = relationship("ProductImage", back_populates="product", cascade="all, delete-orphan", order_by="ProductImage.order")`

### Файл: `seed_data.py` или миграция
- Создать миграцию Alembic для таблицы `product_images`

## Шаг 2: Веб-панель

### Файл: `admin_web/routes.py`
- Добавить маршрут `POST /products/{product_id}/upload-image` — загрузка фото к существующему товару
- Добавить маршрут `POST /products/{product_id}/delete-image/{image_id}` — удаление фото
- Обновить `GET /products/{product_id}/edit` — загружать images для товара
- Обновить `POST /products/add` — сохранять первое фото если есть

### Файл: `admin_web/templates/product_form.html`
- Добавить секцию "Фотографии товара" с сеткой превью
- Кнопка "Добавить фото" — загрузка через AJAX
- Кнопка "Удалить" на каждой фотографии
- Текущее поле image_url заменить на список

### Файл: `admin_web/static/css/custom.css` (или inline)
- Стили для сетки фотографий
- Стили для кнопки удаления

## Шаг 3: Telegram бот

### Файл: `bot/handlers/catalog.py`
- Обновить `cb_handle_product`:
  - Загружать `product.images` из БД
  - Если есть фото — использовать `bot.send_media_group` для показа всех фото
  - Если фото нет — использовать текущую логику

## Шаг 4: Миграция

### Файл: `migrations/versions/`
- Создать миграцию для добавления таблицы `product_images`
- Перенести существующие `image_url` из `products` в `product_images`

## Шаг 5: Тестирование
1. Создать товар с фото через веб-панель
2. Добавить ещё фото к существующему товару
3. Удалить фото
4. Проверить отображение в Telegram

1. `bot/models.py` — добавить ProductImage

4. `bot/handlers/catalog.py` — отображение в Telegram
