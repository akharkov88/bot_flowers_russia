# План реализации: Telegram-бот «Цветы по русски»

## Сводка

Полноценный сервис на базе Telegram-бота + FastAPI веб-панели для цветочного магазина «Цветы по русски» (Вятская д.7, Нижний Новгород). Клиенты浏览ют каталог букетов, формируют корзину, оформляют доставку. Администратор управляет товарами и заказами через Telegram и веб-панель с авторизацией.

**Стек:** Python 3.11+, aiogram 3.x, PostgreSQL (SQLAlchemy ORM), FastAPI, Jinja2, Alembic

**Стиль:** Русский народный (эмодзи 🌸🌺🌻🌷🌹, тёплые тона, традиционные цвета в веб-панели — красный, золотой, белый)

## ORM-модели (bot/models.py)

| Модель | Поля |
|--------|------|
| **Category** | id, name, image_url, is_active, created_at |
| **Product** | id, name, description, price, category_id, composition, image_url, is_active, created_at |
| **User** | id, telegram_id (unique), username, first_name, last_name, phone, created_at |
| **Order** | id, user_id, status (new/processing/confirmed/delivered/cancelled), total_price, delivery_address, delivery_date, delivery_time, phone, comment, created_at, updated_at |
| **OrderItem** | id, order_id, product_id, quantity, price |

## Функционал: Клиентская часть (Telegram)

1. **/start** — приветствие в русском народном стиле, адрес магазина, главное меню
2. **Каталог** — просмотр категорий → товаров → детальной карточки товара (фото, описание, состав, цена)
3. **Корзина** — добавление товаров, изменение количества (+/-), удаление, подсчёт итога
4. **Оформление заказа (FSM)** — пошаговая форма: адрес → дата → время → телефон → комментарий → подтверждение
5. **Мои заказы** — история заказов со статусами (🆕 Новый, ⏳ В обработке, ✅ Подтверждён, 🚚 Доставлен, ❌ Отменён)
6. **Контакты** — адрес (Вятская д.7, Нижний Новгород), режим работы

---

## Функционал: Админ-панель (Telegram)

1. **Проверка прав** — доступ только для указанных telegram_id из `.env`
2. **Меню** — «Товары», «Заказы», «Статистика», «Назад»
3. **Управление товарами** — список, добавление (пошаговая форма), редактирование, скрытие (soft delete)
4. **Управление заказами** — список с фильтром по статусу, просмотр деталей, смена статуса
5. **Статистика** — всего заказов, выручка, по статусам, последние заказы
6. **Уведомления** — автоматическое сообщение админу при новом заказе

## Функционал: Веб-панель (FastAPI)

### Авторизация
- Страница входа (логин/пароль)
- Сессии через `fastapi-session` или JWT
- Пароли хранятся хешированными (werkzeug.security или passlib)

### Маршруты
| Маршрут | Описание |
|---------|----------|
| `/login` | Страница входа |
| `/` | Дашборд: заказы, выручка, последние заказы, распределение по статусам |
| `/orders` | Список заказов с фильтрами (статус, дата) |
| `/orders/{id}` | Детали заказа, смена статуса |
| `/products` | Список товаров |
| `/products/add` / `/products/{id}/edit` | Добавление/редактирование товара |
| `/categories` | Управление категориями |
| `/customers` | Список зарегистрированных пользователей |
| `/stats` | Расширенная статистика |

### REST API (`/api/...`)
- CRUD для заказов, товаров, категорий
- GET `/api/users` — список пользователей
- GET `/api/stats` — статистика

### Загрузка фото
- Загрузка файлов через форму (multipart/form-data)
- Сохранение в `admin_web/static/uploads/products/`
- Превью при редактировании

### Стиль
- Цвета: красный `#C41E3A`, золотой `#D4AF37`, тёплый белый `#FFF8F0`, тёмно-коричневый текст `#2C1810`
- Адаптивные таблицы, карточки для дашборда

## Пошаговый план реализации

### Фаза 1: Настройка проекта
1. Создать структуру директорий и `__init__.py` файлов
2. Создать `requirements.txt`
3. Установить зависимости: `pip install -r requirements.txt`
4. Создать `.env` и `.gitignore`
5. Инициализировать Alembic: `alembic init migrations`

### Фаза 2: Конфигурация и база данных
6. `bot/config.py` — Settings через pydantic-settings
7. `bot/database.py` — async SQLAlchemy engine, session factory, init_db()
8. `bot/models.py` — все ORM-модели
9. Настроить Alembic (env.py → модели из bot.models)
10. Создать миграцию: `alembic revision --autogenerate -m "Initial"` + `alembic upgrade head`

### Фаза 3: Утилиты
11. `bot/utils/logger.py` — логгер с console + file handlers
12. `bot/middlewares/tracking.py` — middleware для учёта пользователей в БД

### Фаза 4: Клавиатуры и состояния
13. `bot/keyboards.py` — все inline-клавиатуры + callback_data классы
14. `bot/states.py` — FSM состояния для OrderForm

### Фаза 5: Обработчики бота
15. `bot/handlers/__init__.py` — регистрация всех роутеров
16. `bot/handlers/start.py` — /start, приветствие, главное меню
17. `bot/handlers/catalog.py` — категории → товары → детальная карточка
18. `bot/handlers/cart.py` — корзина (FSM storage: dict {product_id: quantity})
19. `bot/handlers/order.py` — FSM-форма заказа (адрес → дата → время → телефон → комментарий → подтверждение)
20. `bot/handlers/user_orders.py` — история заказов пользователя
21. `bot/handlers/admin.py` — админ-меню, управление товарами/заказами, статистика, уведомления о новых заказах

### Фаза 6: Главный файл бота
22. `bot/main.py` — инициализация Bot + Dispatcher, регистрация middleware и handlers, запуск polling

### Фаза 7: Веб-панель админа
23. `admin_web/auth.py` — авторизация (логин/пароль, passlib для хеширования)
24. `admin_web/main.py` — FastAPI приложение, настройка template + static
25. `admin_web/routes.py` — HTML маршруты (Jinja2)
26. `admin_web/api.py` — REST API endpoints
27. HTML-шаблоны (base, dashboard, orders, order_detail, products, product_form, categories, customers, stats)
28. CSS `admin_web/static/css/style.css` — русский народный стиль
29. JS `admin_web/static/js/main.js` — интерактивность форм

### Фаза 8: Интеграция и полировка
30. `seed_data.py` — начальные данные (категории + примеры товаров)
31. `run.sh` — скрипт запуска (бот + веб-панель вместе)
32. Обновить `README.md` — описание, установка, запуск
33. `.gitignore` — исключить .env, .venv, *.pyc

## Стратегия проверки

### Ручное тестирование
1. `/start` — приветствие и меню отображаются
2. Каталог — навигация по категориям и товарам
3. Карточка товара — фото, описание, состав, цена
4. Корзина — добавление, изменение количества, удаление, итог
5. Оформление — полный цикл заказа с заполнением всех полей
6. История заказов — просмотр своих заказов
7. Админ-меню (Telegram) — управление товарами и заказами
8. Веб-панель — вход, дашборд, CRUD операций
9. Уведомления — админ получает сообщение о новом заказе
10. Права доступа — не-админ не имеет доступа к `/admin`

### SQL-проверки
```sql
SELECT * FROM users;
SELECT * FROM products;
SELECT o.id, o.status, o.total_price, o.delivery_address, u.username
FROM orders o JOIN users u ON o.user_id = u.id;
SELECT oi.quantity, oi.price, p.name FROM order_items oi JOIN products p ON oi.product_id = p.id;
```

### Краевые случаи
- Пустая корзина → кнопка «Оформить» неактивна
- Невалидный формат даты/телефона → сообщение об ошибке
- Не-админ → `/admin` с сообщением «Доступ запрещён»
- Неактивные товары → не отображаются в каталоге
