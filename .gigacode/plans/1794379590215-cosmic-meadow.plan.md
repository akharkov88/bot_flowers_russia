# План: Уведомления о заказах в Telegram-чат

## Задача
При создании нового заказа дублировать информацию о нём в Telegram-чат `@-4200712474`.

## Контекст
- Заказы создаются в `bot/handlers/order.py` → `process_comment` (строка ~130)
- Уже есть функция `notify_admin(bot, order)` в `bot/handlers/admin.py` — **никогда не вызывается**
- Функция уже формирует красивый текст уведомления с составом заказа, адресом, датой, временем, телефоном
- Используется Aiogram 3.x с async Bot API

## Изменения

### 1. `bot/config.py` — добавить поле chat_id
```python
order_chat_id: int = -4200712474  # Telegram chat ID для уведомлений о заказах
```

### 2. `bot/handlers/admin.py` — расширить `notify_admin`
Добавить отправку уведомления в чат:
```python
async def notify_admin(bot: Bot, order: Order):
    # ... существующий код отправки админам ...
    
    # Отправка в чат
    try:
        await bot.send_message(settings.order_chat_id, text)
    except Exception as e:
        logger.warning(f"Cannot send order notification to chat: {e}")
```

### 3. `bot/handlers/order.py` — вызвать `notify_admin`
После `await db_session.commit()` добавить:
```python
from bot.handlers.admin import notify_admin
# ... после commit ...
try:
    await notify_admin(bot, order)
except Exception as e:
    logger.error(f"Failed to notify about order #{order.id}: {e}")
```

### 4. `bot/handlers/order.py` — получить bot из DI
Добавить параметр `bot: Bot` в сигнатуру `process_comment`.

## Файлы для изменения
1. `bot/config.py` — добавить `order_chat_id`
2. `bot/handlers/admin.py` — расширить `notify_admin`
3. `bot/handlers/order.py` — вызвать `notify_admin` после создания заказа

## Проверка
1. Оформить заказ через бота
2. Убедиться, что в чат `-4200712474` пришло уведомление
3. Убедиться, что пользователь получил подтверждение (не должно ломаться)
