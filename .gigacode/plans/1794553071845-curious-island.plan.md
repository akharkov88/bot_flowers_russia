# План: Система рассылки постов клиентам

## Обзор
Добавить в админ-панель страницу для создания и отправки постов с фотографиями, текстом и кнопкой. Поддержка мгновенной и запланированной рассылки. Выбор аудитории (все или конкретные пользователи). Детальная статистика отправленных постов.

## Архитектура

### Новые модели (bot/models.py)
1. **Post** — посты для рассылки
   - id, title, text (контент поста)
   - images (JSON: список URL изображений)
   - button_text, button_url (текст и URL кнопки)
   - send_type: "instant" | "scheduled"
   - scheduled_at: datetime (для запланированных)
   - status: "draft" | "sending" | "sent" | "failed"
   - sent_at: datetime (когда отправлен)
   - created_at, updated_at

2. **PostRecipient** — получатели конкретного поста
   - id, post_id, user_id
   - status: "pending" | "sent" | "failed"
   - sent_at, error_message

3. **PostStats** — статистика по посту
   - post_id, total_sent, total_failed, total_pending

### Бот (aiogram)

#### Фоновый процесс (bot/main.py)
Добавить задачу `process_post_scheduled()`:
- Проверяет посты со статусом "scheduled" и `scheduled_at <= now`
- Меняет статус на "sending"
- Отправляет пост всем выбранным пользователям
- Для каждого пользователя создаёт PostRecipient
- Создаёт InlineKeyboardButton с текстом и URL
- Отправляет фото с caption (текст поста) + кнопка
- Обновляет статусы PostRecipient
- Обновляет PostStats

#### Функция отправки
```python
async def send_post_to_user(bot, user, post, recipient):
    # Создать клавиатуру с кнопкой
    keyboard = InlineKeyboardMarkup(inline_keyboard=[[InlineKeyboardButton(text=post.button_text, url=post.button_url)]])
    # Отправить фото
    await bot.send_photo(
        chat_id=user.telegram_id,
        photo=post.images[0] if post.images else None,
        caption=post.text,
        reply_markup=keyboard
    )
    # Обновить статус
    recipient.status = "sent"
    recipient.sent_at = datetime.now(timezone.utc)
```

### Статусы поста
- `draft` — черновик
- `sending` — процесс отправки
- `sent` — все успешно отправлены
- `failed` — есть ошибки отправки
- `scheduled` — запланирован

### Статусы получателя
- `pending` — ожидает отправки
- `sent` — успешно отправлен
- `failed` — ошибка отправки
